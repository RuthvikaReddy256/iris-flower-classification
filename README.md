# Iris Flower Classification

## Objective
This project classifies iris flowers into three species using Machine Learning.

## Algorithm
K-Nearest Neighbors (KNN)

## Dataset
Scikit-learn Iris Dataset

## Libraries
- pandas
- numpy
- scikit-learn
- matplotlib
- seaborn

## Evaluation
- Accuracy
- Precision
- Recall
- Confusion Matrix

## Results
Model achieved approximately 97%–100% accuracy.# iris-flower-classification
